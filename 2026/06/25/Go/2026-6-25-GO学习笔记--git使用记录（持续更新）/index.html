git基本使用范例

将本地项目代码提交到你刚刚创建的 GitHub 仓库，主要分为 准备、配置、提交与推送 几个步骤。

第一步：准备工作

在开始前，确保已满足以下条件：

  1. 拥有一个 GitHub 账号：如果还没有，需要先去 GitHub 官网 注册一个。
  2. 电脑上已安装 Git：可以在终端（Terminal）或命令提示符（CMD）中输入 git --version 来检查是否安装。如果未安装，可以从 Git 官网 下载。
  3. 创建好一个空的 GitHub 仓库：在你的 GitHub 主页，点击右上角的 + 号，选择 New repository，填写仓库名后创建。

    重要提示：创建时，不要勾选 “Add a README”、“Add .gitignore” 等选项，确保远程仓库是完全空的，以避免后续推送时出现冲突。

第二步：在本地执行 Git 命令
