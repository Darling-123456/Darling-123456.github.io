Go语言&Goland 安装及配置教程

一、安装Go语言 (Golang)

1. 下载安装

  • 在Golang官网下载（Windows版）
  • 一直NEXT
  • 修改安装路径
  • Finish

2. 配置环境变量

  • 计算机（右键）→属性→高级系统设置→（点击）环境变量
  • GOROOT：Go的安装路径
    新建一个系统变量
  • GOPATH：自定义一个工作区目录（存放代码、依赖库等）
    新建一个系统变量

    检查GOPATH用户变量（要与上面的系统变量一致）
  • PATH：go的bin目录，通常安装golang后，系统会自动配置
    检查一下

二、安装Goland IDE

1. 下载安装

  • 在GoLand官网下载
  • 修改安装路径
  • 勾选快捷方式
  • 安装
  • 不要勾选运行，直接点击完成

2. 首次配置

配置之前需要激活，这个大家可以自行上拼夕夕进行搜索，或者扭头用vscode也可以

基本配置：

打开Goland → File → Settings → Go → GOROOT，点击 +，选择Go的安装路径

顺便检查一下 GOPATH （在 Settings → Go → GOPATH 中检查）

Go Modules 设置：

  • GOPROXY：管理依赖的核心
  • GOSUMDB：用于验证下载的依赖包是否被篡改，确保安全性

3.创建项目验证

重启后创建

  • 新建项目：
    File → New → Project → 选择位置 → 设置包名 → 勾选Add sample code


可以看到已经有简单的代码在main.go中了

  • 运行后可以在下方看到对应输出，成功

三、常用命令速查

命令 说明
go version 查看Go版本
go env 查看环境变量
go mod init <name> 初始化模块
go mod tidy 整理依赖
go run <file> 运行程序
go build 编译程序
go build -o <name> 编译并指定输出名
go fmt 格式化代码
go test 运行测试
go get <pkg> 下载依赖
