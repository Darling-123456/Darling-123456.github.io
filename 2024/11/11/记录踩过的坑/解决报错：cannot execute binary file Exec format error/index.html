解决报错：cannot execute binary file: Exec format error

一、兼容性原因

该错误发生时，通常是在尝试执行一个不兼容的二进制文件。很可能是因为该二进制文件运行在一个不同体系架构的操作系统中，比如 64 位的可执行文件在 32 位 Linux 操作系统运行，就会出现这种情况。
